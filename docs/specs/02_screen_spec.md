# 画面仕様

## 画面階層
- トップページ（SCR-00 大分類ポータル）で介護保険システムの9大分類を表示する
- 「被保険者資格」を選択すると被保険者資格ダッシュボード（SCR-DB）へ遷移する
- 各業務画面（SCR-01〜07）は被保険者資格ダッシュボードから辿る
- 被保険者資格以外の8大分類は表示のみで遷移しない（詳細は `docs/standards/03_business_categories.md`）

```text
SCR-00 大分類ポータル
  └─ 被保険者資格を選択
       └─ SCR-DB 被保険者資格ダッシュボード兼メニュー
            ├─ SCR-01 住民異動イベント一覧/取込
            ├─ SCR-02 被保険者一覧 → SCR-03 被保険者詳細
            │                          ├─ SCR-04 資格登録
            │                          ├─ SCR-05 被保険者証プレビュー
            │                          └─ SCR-07 再交付申請
            └─ SCR-06 証発行履歴
```

## 共通画面ルール
- 画面右上または下部に「対応業務」を表示する（機能ID・帳票IDは表示しない）
- shadcn/uiのTable, Card, Button, Badge, Dialog, Formを利用する
- 業務エラーは赤色のAlertで表示する
- pending/processed/errorなどの状態はBadgeで表示する

## UI・レイアウト（確定デザイン）
配色・サイドバー・ポータルカード等の詳細は **`docs/specs/08_ui_design_guide.md`** を正とする。要点のみ:

| 画面 | レイアウト |
|---|---|
| SCR-00 | サイドバーなし。9大分類カード（同一デザイン・各分類に短い説明文） |
| SCR-DB 以降 | 左: ダークグラデーションサイドバー（白文字・三本線でメニュー文字トグル） / 上: ヘッダー / 中: メイン |

- メインエリアのアクセント色は **インディゴ**（`globals.css` の `--primary`）。緑・ティールは使わない
- 9大分類の名称・説明・活性の定義は `docs/standards/03_business_categories.md` および `frontend/lib/business-categories.ts`
